🎵 Music Player

A web-based music player with playlist management, search, and audio controls built using HTML, CSS, and JavaScript.

✨ Features

-Play/Pause, Next/Previous - Full audio controls
-Shuffle & Repeat - Random playback and loop modes
-Volume Control - Slider with mute toggle
-Progress Bar - Click to seek through songs
-Search Songs - Real-time search by title or artist
-Recently Played - Automatically tracks played songs with clear button
-Responsive Design - Works on desktop and mobile

🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript 
- Font Awesome Icons

🚀 How to Use

1. Clone the repository
   ```bash
   git clone https://github.com/emanfatima931/music-player.git

   Add your MP3 files to songs/ folder

2. Add cover images to images/ folder

3. Open index.html in your browser

4. Click any song to start playing
